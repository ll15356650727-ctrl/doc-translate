# 目标管理使用说明

团队负责人可以创建目标，团队成员只能更新自己负责的关键结果。

## 更新进度

1. 打开目标详情，选择需要更新的关键结果。
2. 填写进展说明后保存；进度更新不需要负责人审核。

| 字段 | 说明 |
| --- | --- |
| 截止日期 | 2026-12-31 |
| 提醒阈值 | 完成率低于 60% 时提醒负责人 |

> 删除目标后不能恢复，请先确认。

查看 [帮助中心](https://example.org/help)。接口字段 `goal_id` 和变量 {member_name} 必须保留。

```json
{"goal_id": "goal-001", "progress": 60}
```
