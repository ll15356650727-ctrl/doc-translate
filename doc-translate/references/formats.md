# 1.0 格式边界

## Markdown 与 TXT

TXT 默认严格识别 UTF-8（含 BOM）及带 BOM 的 UTF-16；其他编码需要 `prepare --encoding gb18030` 等明确指定。保留编码、BOM、换行符和原文缩进；译文超出原编码字符集则报错，不静默替换字符。

Markdown 按行与表格单元格提取，保留标题、列表、引用、表格分隔行及原始空行。代码围栏、行内代码、Frontmatter、HTML 块和引用链接定义不送译；这些保留区会进入报告。链接目标、图片目标、自动链接、格式标记、变量与数值均受保护。图片 alt 可翻译，图片本身不处理。

本版使用保守语法扫描，不声称覆盖所有 Markdown 方言。复杂多行 HTML、嵌套指令及多行 Frontmatter 异常应先确认；未闭合代码块/Frontmatter 阻断该文件。新增译文不得注入换行、额外表格管道或新的语法结构。

## Word

直接修改 DOCX 压缩包中的正文、表格、页眉页脚、脚注、尾注和批注的 `w:t` 文本；关系、样式、图片、对象及其他压缩包成员保持原有内容。无需第三方包。

以文本节点为单位翻译；同段落其他文本作为上下文。文字被不同样式切成多个节点时会标记提示；可调整每个节点的译法，但不要把所有译文塞进第一个节点导致样式错配。确需跨节点重排的复杂句改为明确适配任务，不能宣称已完全还原。

含字段、修订、文本框、公式、内容控件等复杂结构的段落保留原样并标待检查；不擅自接受修订或翻译字段缓存值。图表、嵌入对象、图片中文字以及非 WordprocessingML 文字不属于本版自动翻译范围，会列入限制。数字签名或宏包不支持，直接阻断。

源摘要变化则禁止回填；必须重跑 prepare。回填后重新解析所有 XML，验证非文本 XML 结构及未修改 ZIP 成员。输出能解析不等于能在所有版本 Word 中正确显示。

可用 Word/文档渲染工具时逐页检查标题、表格、页眉页脚、字体和换行；译文变长允许自然换页，不要求页数与原文绝对相等。缺工具时如实记录版面 UNVERIFIED。
