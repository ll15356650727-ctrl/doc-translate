# 专业文档翻译与校对 1.0.0

发布日期：2026-10-15。

提供 Markdown、TXT、Word 的首次翻译、增量更新和已有译文审校。用户给出文件与目标语言即可，由执行者完成翻译和上下文审校，脚本处理提取、术语锁定、去重、回填及结构检查。适合批量资料和持续更新的项目，少量短句直接翻译即可。

## 立项判断

三个独立使用场景：产品帮助文档批量翻译；通知和操作资料持续更新；供应商提供译稿的交付前审校。下游直接使用译文文件，遇到问题可用报告定位片段。

与脱敏、PRD 或通用文档编辑的目标不同：本技能维护原文/译文关系、术语及可恢复的翻译状态，不改业务事实或脱敏规则。

可机械验证的不变量包括：源摘要不变；保护标记每个恰好一次；Word 非文本结构与资源不变；已确认译文不能被普通响应覆盖；目标语言改变后旧响应失效。

## 已完成能力

- 标准库脚本，不调用翻译 API，无运行时第三方 Python 包。
- 文件目录预检、批次预算、上下文相关去重、译文复用。
- 确认术语替换、变量与数值保护、Markdown 保留区域处理。
- Word 正文、表格、页眉页脚、脚注、尾注、批注文本节点处理。
- 部分响应导入、失败隔离、旧输出归档、确认译文冲突处理。
- 原文/译文审校模式，独立报告机械检查、语义和版面状态。
- 格式与版面人工复核记录绑定文件摘要，修改后失效。
- 1024×1024 PNG 图标、语义版本、原作者署名及离线分发包。

## 验证证据

行为回归 27 项通过，覆盖错号标记、错误数值、未闭合 Markdown、未知片段、旧语言响应、Word 跨段落字段、UTF-16 BOM 和 CRLF、输入变化、删除文件、确认冲突等场景。

真实示例在 [1.0.0 示例](../../示例/doc-translate-1.0.0-example/)：3 个有效文件，28 个片段；首次完成所有响应导入，机械检查通过，已记录上下文审校。Word 英文版由文档渲染器生成全部 1 页 PNG，已检查可读性、表格、页眉页脚，无遮挡或溢出。源文件保持原样。

同一输入重复 prepare：28 个片段全部复用，待译唯一片段 0，待译字符 0。该证据仅说明这组样例的缓存行为，不是通用节省比例，也没有实测模型 Token。

已有译稿审校示例：Markdown 译文保护检查通过。错误金额和标题层级变化通过回归夹具验证会被检测。

## 当前限制

1. Excel、PPT、PDF、图片尚未支持，不纳入本版承诺。
2. Markdown 使用保守扫描，复杂 HTML、深层缩进和方言需检查。
3. Word 以文本节点翻译，跨样式节点重排可能需单独适配；字段、修订、文本框等复杂段落保留并报告。
4. 语义准确性依赖实际上下文审校，机械检查通过不能代表准确率。版面工具缺失时保持未验证。
5. 短文件首次运行的批次协议会产生额外开销，本技能主要价值来自批量、复用和检查。
